# Культ Трости — сайт интерактивного стенда

Статический сайт команды **Культ Трости** с отдельной мини-страницей проекта **Bendy Road**. Репозиторий полностью готов к публикации через **GitHub Pages**: без npm, сборщика и серверной части.

## Что есть на сайте

- главная страница команды и интерактивного стенда;
- блок активностей: аркадный автомат, рисование, интерактивы и мерч;
- галерея атмосферы стенда;
- мероприятия: ИндиКон и Alia Fest;
- раздел собственных проектов;
- отдельная страница `bendy-road.html`;
- Telegram и VK;
- бесшовные бегущие строки;
- фиксированная шапка;
- рабочее мобильное меню;
- кликабельные быстрые кнопки «Активности / Игры / Оформление / Мерч»;
- адаптивная вёрстка для iPhone и других мобильных экранов.

## Мобильная версия

В актуальной версии отдельно доработаны узкие экраны:

- шапка остаётся закреплённой сверху и не уезжает при прокрутке;
- основной контент автоматически получает корректный отступ под фиксированную шапку;
- заголовки секций не пересекаются с номерами разделов;
- карточки активностей складываются в одну колонку;
- фотографии в «Атмосфере стенда» сохраняют пропорции и не наезжают друг на друга;
- карточки мероприятий, проекта и контактов перестраиваются под ширину телефона;
- учтены `viewport-fit=cover` и safe-area для iPhone;
- устранён горизонтальный скролл на узких экранах.

Вёрстка проверялась на ширинах **375 px, 390 px и 430 px**, а также на планшетном и десктопном представлении.

## Локальный запуск

Сайт полностью статический. Для простой проверки можно открыть `index.html` напрямую.

Для режима, максимально близкого к GitHub Pages, из корня репозитория можно запустить:

```bash
python -m http.server 8000
```

И открыть:

```text
http://localhost:8000/
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое этой папки в корень репозитория** — `index.html` должен находиться в корне.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Нажмите **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages.

Файл `.nojekyll` уже добавлен.
