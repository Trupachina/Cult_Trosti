# Культ Трости — сайт интерактивного стенда

Статический одностраничный сайт команды **Культ Трости** с отдельной мини-страницей проекта **Bendy Road**. Проект подготовлен для публикации через **GitHub Pages** и не требует сборщика, npm или серверной части.

## Что есть на сайте

- главная страница команды и интерактивного стенда;
- блок активностей: аркадный автомат, рисование, интерактивы и мерч;
- галерея;
- мероприятия: ИндиКон и Alia Fest;
- раздел проектов;
- отдельная страница `bendy-road.html`;
- ссылки на Telegram и VK;
- адаптивная верстка для компьютеров и мобильных устройств;
- анимации появления элементов и бесшовные бегущие строки на главной и Bendy Road;
- бегущие строки останавливаются при наведении курсора;
- favicon и локальные изображения без внешних зависимостей.

## Локальный запуск

Сайт полностью статический. Для быстрой проверки можно просто открыть `index.html` в браузере.

Для поведения, максимально близкого к GitHub Pages, удобнее запустить локальный HTTP-сервер из корня репозитория:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000/
```

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **содержимое этого каталога в корень репозитория**. Файл `index.html` должен лежать именно в корне.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Нажмите **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages.

`.nojekyll` уже добавлен, поэтому GitHub Pages будет раздавать файлы проекта напрямую, без обработки Jekyll.
